# notes

調べたことをまとめて置いておく場所。GitHub Pages で公開しているので、URL を送れば誰でも読めます。

**https://ktgwshota.github.io/notes/**

---

## ⚠️ 公開可否チェック（記事を追加する前に必ず）

このサイトは **インターネット上の誰でも読める公開サイト**です。アクセス制限はありません。
記事を push する前に全文を走査し、以下が 1 つでも含まれていたら **その記事は追加しない**でください。

| 分類 | 具体例 |
| --- | --- |
| 顧客・取引先の情報 | 企業名、サービス名、案件コード、顧客サイトの URL・ドメイン |
| 社内システムの情報 | リポジトリ名、内部ツール名、管理画面・Notion・Jira・Sentry の URL |
| ソースコード由来の情報 | 自社コードの抜粋、ファイルパス、関数名、テーブル名、カラム名、API エンドポイント |
| 認証情報 | トークン、API キー、パスワード、環境変数の値 |
| 個人情報 | 氏名、メールアドレス、アカウント名、Slack の発言 |
| 事業情報 | 売上、KPI、ユーザー数、契約条件、未公開の機能やリリース予定 |
| 障害・インシデント | 発生日時、影響範囲、原因の詳細 |

**グレーだと感じた時点で「含まれている」と判定します。** 記事を出すことより、出してはいけないものを出さないことが優先です。

### 社内の調査がきっかけの記事を書くとき

一般的な技術知識として成立する形に書き直します。固有名詞を消すだけでは不十分で、調査の経緯や結論が特定の案件に紐づいたままなら書き直しが必要です。

- ❌ 「◯◯社のサイトで計測タグが原因で bfcache が効かなかった」
- ⭕ 「計測タグが `unload` を使っていると bfcache が無効になる」

読者が前提知識なしで読めて、かつ誰にでも当てはまる内容になっていれば合格です。

## 記事の追加手順

1. ルートにディレクトリを 1 つ作り、その中に `index.html` を置く
2. `<head>` に以下を書く（この 4 つが一覧の生成元になります）

   ```html
   <title>記事タイトル — notes</title>
   <meta name="description" content="一覧に出す要約">
   <meta name="date" content="2026-09-16">
   <meta name="tags" content="browser,performance">
   <link rel="stylesheet" href="../assets/style.css">
   ```

3. **公開可否チェックを実施する**
4. main に push する

トップページの記事一覧は **push 時に GitHub Actions が自動生成** します（[build-index.yml](.github/workflows/build-index.yml)）。`index.html` を手で編集する必要はありません。日付の降順で並びます。

手元で先に確認したい場合はこれを実行します。

```
python3 scripts/build_index.py
```

## 構成

```
.
├── index.html               記事一覧（自動生成・手で編集しない）
├── assets/style.css         全記事で共有するスタイル
├── scripts/build_index.py   一覧の生成スクリプト
└── <slug>/index.html        記事本体
```

スタイルは `assets/style.css` に集約しています。色はすべて CSS 変数で定義し、ライト／ダーク両方のテーマに対応済みです。記事側で色を直接書かず、変数を使ってください。

## 使えるコンポーネント

| クラス | 用途 |
| --- | --- |
| `.masthead` / `.eyebrow` / `.lede` | 記事ヘッダー |
| `.premise` | 前提・注記のボックス |
| `.matrix` / `.row` / `.verdict` | 比較マトリクス（横スクロール対応） |
| `.chip.is-block` / `.is-cond` / `.is-ok` | 判定チップ（赤／黄／緑） |
| `.card-list` | 並列項目のカード一覧 |
| `.steps` | 番号付きの手順リスト |
| `.entries` | トップページの記事一覧 |
